# باب الحارة — الجزء الأول · وثيقة التصميم والنسخة التجريبية

> هذه وثيقة عمل حيّة. قسم «حالة التنفيذ» في آخرها يوضح بصدق ما هو قابل للعب الآن وما ينتظر أصولاً أو مراجع.

## 1. قرار المحرك والمنصة

| البند | القرار | السبب |
|---|---|---|
| المحرك | **Three.js r186 (WebGL2)** مضمَّن داخل `vendor/` | البيئة الحالية لا تتضمن Unity/Unreal ولا يمكنها تشغيل محرر ثقيل؛ المتصفح يتيح لعبة ثلاثية الأبعاد حقيقية تُلعب برابط واحد، بلا تثبيت وبلا إنترنت (لا CDN). |
| المنصة | متصفحات سطح المكتب الحديثة (Chrome/Edge/Firefox/Safari) بلوحة المفاتيح والفأرة | أسرع طريق لنسخة قابلة للعب. التوسّع لاحقاً: غلاف Tauri/Electron لسطح المكتب، ودعم اللمس/اليد. |
| اللغة | JavaScript (ES Modules) بلا خطوة بناء | أي شخص يشغّلها بـ `node scripts/serve.mjs`. |
| الأصول | **كلها مولَّدة برمجياً** (خامات Canvas، مجسمات، صوت WebAudio) | لا ملفات نماذج أو تسجيلات متوفرة في البيئة؛ كل شيء قابل للاستبدال عبر واجهات واضحة (انظر §6). |
| الواجهة | HTML/CSS عربية RTL فوق الـ Canvas، خطوط Reem Kufi / Noto Naskh / Amiri مضمّنة | أفضل تشكيل للحروف العربية وأسهل تنسيق من الرسم داخل WebGL. |

### حدود صريحة
* جودة «الواقعية» المطلوبة (وجوه وملابس بدقة الممثلين) **لا تتحقق بمجسمات برمجية**. النسخة الحالية تعطي جوّاً سينمائياً (إضاءة فيزيائية، ظلال، ضباب، خامات حجرية وخشبية، تبديل ليل/نهار) لكن الشخصيات **نماذج مؤقتة مجسَّمة بالأشكال الأساسية** مصمَّمة لتُستبدل بنماذج حقيقية (glTF) ومزامنة شفاه مبنية على Blend Shapes.
* لا يوجد تسجيل صوتي بشري. الحوارات تُسمَع بـ«صوت مؤقت» مولَّد (نبرة لكل شخصية، ومزامنة شفاه حقيقية على مستوى الحرف) ومعها ترجمة عربية كاملة، وخيار تجريبي لاستخدام صوت عربي من المتصفح إن وُجد.
* لم تُوفَّر مراجع للمسلسل، لذلك **لم أنسب أي حدث أو سمة شخصية إلى المسلسل**. الشخصيات في العرض التجريبي أدوار بأسماء مؤقتة (`data/characters`) تُربط بالشخصيات المعتمدة عند تزويدي بالمراجع. المهمة الرئيسية في العرض **أصلية** وموسومة بذلك داخل اللعبة.
* لا تُدمج هيئات الممثلين وأصواتهم قبل وجود تراخيص وموافقات موثّقة.

## 2. تصور القصة (العرض التجريبي: «ساعة أبو جلال» — مهمة أصلية)

**المكان والزمان:** حارة شامية، ساعة العصر وحتى ما بعد المغرب (≈ 4:45 م → 7:00 م بزمن اللعبة، يمرّ بمعدل 6 ثوانٍ لكل ثانية حقيقية).

**البطل (قابل للّعب):** نديم — شاب من الحارة (شخصية أصلية).

**الحبكة:** ضاعت ساعة الجيب التي ورثها صاحب المقهى عن أبيه. يطلب من نديم البحث بهدوء قبل أن يعلم العكيد فتنقلب الحارة. العكيد يميل لاتهام بائع جوّال غريب. أم حسن تخفي شيئاً لتحمي ابنها. الحقيقة: الولد حسن (10 سنوات) أخذ الساعة ليرى كيف تدق، فانقطعت السلسلة وخاف، فخبّأها في حجر سائب بمصطبة الحجر قرب البحرة.

**الشخصيات المحاوَرة (3):** صاحب المقهى · العكيد · الجارة أم حسن — لكل منها ثقة تبدأ بقيمة، وتتغير بخيارات اللاعب، وتفتح أو تغلق أسطر حوار.

**الأدلة (6):** قائمة الشهود · سلسلة مقطوعة عليها بصمة صغيرة · اتهام العكيد للبائع (غير مثبت) · آثار أقدام صغيرة مبلولة · تلميح أم حسن · الساعة نفسها.

**ضغط الزمن:** إن بلغت الساعة 6:20 م ولم تُحسم القضية يوقف العكيد البائع (تتبدّل الموسيقى إلى التوتر وتتغير مهمة الهدف).

**النهايات (4)** تحسبها الخيارات + الثقة + السمعة:
1. **الستر** — تعيد الساعة بصمت وتحمي الولد.
2. **العفو** — تصدق القول وتطلب العفو؛ تنجح فقط إذا كانت ثقة أبي جلال كافية.
3. **الهيبة** — تسلّم الولد للعكيد: نظام صارم، وأم حسن تخسرها.
4. **الظلم** — تتواطأ على اتهام البائع: أسوأ النهايات أخلاقياً.

**السمعة:** محوران — الأمانة والهيبة — تؤثر في عبارات أهل الحارة العابرين.

## 3. الأنظمة

| النظام | التنفيذ في العرض |
|---|---|
| تحكم الشخص الثالث | WASD + ماوس (قفل المؤشر)، كاميرا مريحة بتصادم مع الجدران |
| كاميرا سينمائية | لقطات حوار (فوق الكتف/قريبة) بعدسة أضيق، شريطان سينمائيان، افتتاحية بمسار كاميرا |
| الحوار المتفرع | عقد حوار ببيانات (`src/story/*.js`) بشروط وتأثيرات وخيارات تظهر/تُحجب بالثقة والأدلة |
| الثقة والسمعة | قيم لكل شخصية + محورا سمعة، تظهر كإشعارات ولوحة «العلاقات» |
| التحقيق | تفحّص أغراض العالم، أدلة في دفتر، جرد، أهداف متتالية، علامة هدف |
| الزمن والحياة | دورة ليل/نهار، فوانيس تضيء، سكان يتحركون ويدخلون بيوتهم مساءً، عبارات عابرة حسب السمعة والزمن |
| الصوت | أجواء مكانية 3D (بحرة، مقهى، سوق، صراصير الليل/عصافير النهار)، خطوات، أبواب، موسيقى تتبدّل: هدوء (بياتي) / توتر (حجاز) / حزن (نهاوند) |
| الحفظ | تلقائي (عند الأحداث + كل دقيقة) ويدوي (F5 أو من القائمة) في `localStorage` |
| الإعدادات | جودة رسومية (منخفض/متوسط/عالٍ)، مستويات الصوت، الترجمة، حساسية الكاميرا، صوت المتصفح |
| الواجهة | عربية RTL، تصميم أبلق دمشقي (خطوط حجر أسود/أبيض)، خريطة صغيرة وكاملة، دفتر بأربع تبويبات |

## 4. الأصول المطلوبة للنسخة الكاملة

| الفئة | الحالي (مؤقت/مولَّد) | المطلوب للاستبدال |
|---|---|---|
| وجوه/أجسام الشخصيات | مجسمات أولية بتعابير ومزامنة شفاه | نماذج glTF بهيكل عظمي وBlend Shapes (ARKit 52 أو مكافئ) + موافقات الممثلين |
| الأصوات | صوت تركيبي مؤقت + ترجمة | تسجيلات بلهجة شامية أصلية لكل سطر (`voiceId` جاهز في البيانات) |
| المراجع | لا شيء | سيناريو/ملخص حلقات الموسم الأول، صور للأزياء والديكور، قائمة الشخصيات المعتمدة |
| العمارة | خامات برمجية ومجسمات صندوقية مفصّلة | مسح/نمذجة بيوت دمشقية، خامات PBR حقيقية |
| الموسيقى | تأليف خوارزمي على المقامات | ملحّن/عازف عود وقانون وإيقاعات |

## 5. خارطة طريق مختصرة

1. **(هذا العرض)** قطاع واحد + مهمة تحقيق + 4 نهايات.
2. الفصل الأول: حارة كاملة، 8–10 شخصيات، مواجهات درامية محدودة.
3. اللعب بعدة شخصيات (قدرات ملائمة للدور).
4. استبدال الأصول بالمعتمدة، ثم التغليف لسطح المكتب.

## 7. حالة التنفيذ (محدَّثة)

### قابل للعب فعلياً الآن
| البند المطلوب في العرض | الحالة | ملاحظة |
|---|---|---|
| 1. جزء صغير مفصّل من الحارة | ✅ | ساحة + بحرة + مقهى بعريشة + بقالة + باب الحارة + زقاق غربي مسقوف + مصطبة؛ نهار وغروب وليل |
| 2. شخصية قابلة للعب + 3 شخصيات للحوار | ✅ | نديم (قابل للعب) · أبو جلال · العكيد · أم حسن؛ إضافة إلى بائع جوّال وبقّال وسكان عابرين |
| 3. مهمة تحقيق أصلية عن غرض مفقود، موسومة | ✅ | «ساعة أبو جلال» — الوسم يظهر عند البدء وفي الدفتر وشاشة النهاية |
| 4. حوار متفرع يؤثر في ثقة شخصية | ✅ | ثلاث شخصيات بثقة تتغير، وخيارات تُقفل/تُفتح بالثقة والأدلة (مثلاً: أم حسن، تدخّل العكيد) |
| 5. مشهد افتتاحي + أصوات تجريبية + حفظ | ✅ | افتتاحية بثلاث لقطات مع سرد وترجمة · أجواء وموسيقى وصوت حوار مولَّدة · حفظ تلقائي/يدوي ومتابعة |
| 6. هدف واضح ونهاية تُبيّن النتيجة | ✅ | هدف مشتق من الحالة + علامة هدف + 4 نهايات بملخص للثقة والسمعة والقرارات |

### مؤقت / ينقصه أصول أو مراجع
| البند | الوضع الحالي | يحتاج |
|---|---|---|
| وجوه وأجسام واقعية بتفاصيل الملابس | **نماذج مجسّمة بأشكال أولية** (تعابير وجه، مزامنة شفاه، مشية، جلوس، إيماءات) | نماذج glTF + موافقات الممثلين |
| أصوات شامية أصلية | **صوت تركيبي مؤقت** + ترجمة كاملة + خيار صوت المتصفح التجريبي | تسجيلات شامية لكل سطر |
| شخصيات الموسم الأول وتسلسل أحداثه | **غير مُنفَّذ** — لا مراجع متاحة؛ الأسماء مؤقتة بحسب الدور | سيناريو/ملخصات الحلقات + قائمة معتمدة |
| «جرافيكس سينمائي واقعي» | إضاءة فيزيائية وظلال وضباب وتوهّج (جودة «عالٍ») بخامات مولَّدة | خامات PBR ومسح/نمذجة معمارية حقيقية |
| مواجهات محدودة بحركات وتأثيرات | **غير مُنفَّذ في العرض** (يوجد مشهد توقيف البائع كتوتر درامي دون قتال) | تصميم المواجهات + تحريك |
| اللعب بشخصيات متعددة | **غير مُنفَّذ** — البنية تسمح (Character/Player) | تحديد الأدوار والقدرات |
| اللمس/يد التحكم | غير مُنفَّذ | تصميم تحكم للمس واليد |

### ملاحظات هندسية
* كل المجسمات الثابتة تُدمج حسب الخامة عند التحميل: العالم ≈ 80 استدعاء رسم، ومعه الشخصيات ≈ 280 (جودة «منخفض») و≈ 600 (متوسط بظلال)، مع إخفاء تفاصيل الوجه عن بعد.
* `autoQuality` يخفّض الجودة تلقائياً إذا تدنّى الأداء (متوسط زمن الإطار > 45ms لمدة 5 ثوانٍ).
* لا يمكن التحقق من «سماع» الصوت في بيئة الاختبار؛ يتحقق الاختبار الآلي من أن سلسلة الصوت تنتج إشارة وأن الفم يتحرك، أما جودة الإنصات فتحتاج مراجعة بشرية.
