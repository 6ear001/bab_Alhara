# باب الحارة — الجزء الأول (نسخة تجريبية قابلة للّعب)

لعبة مغامرات درامية ثلاثية الأبعاد بمنظور الشخص الثالث، تدور في حارة شامية. هذه **نسخة تجريبية مدتها 15–20 دقيقة** تضم قطاعاً مفصّلاً من الحارة، شخصية قابلة للعب وثلاث شخصيات محاوَرة، ومهمة تحقيق **أصلية** («ساعة أبو جلال») بحوار متفرع يؤثر في الثقة والسمعة وأربع نهايات.

> وثيقة التصميم الكاملة، قرار المحرك، وجدول «ما هو حقيقي وما هو مؤقت»: [`docs/DESIGN.md`](docs/DESIGN.md)

## التشغيل

لا تحتاج إلى تثبيت أي شيء (Three.js والخطوط مضمّنة في `vendor/`، فتعمل بلا إنترنت):

```bash
node scripts/serve.mjs          # ثم افتح http://localhost:8080
# أو: python3 -m http.server 8080
```

متصفح حديث بدعم WebGL2 (Chrome / Edge / Firefox / Safari). يُنصح ببطاقة رسوم؛ في الأجهزة الضعيفة اختر «منخفض» من الإعدادات (أو دع «التخفيض التلقائي» يعمل).

معاملات اختيارية في الرابط: `?q=low|medium|high` · `?autoq=0` · `?autostart=new|continue`.

## التحكم

| الإجراء | المفتاح |
|---|---|
| الحركة / الركض | `WASD` أو الأسهم / `Shift` |
| الكاميرا | الفأرة (انقر على اللعبة لقفل المؤشر) أو اسحب بالفأرة · `Q`/`Z` تدوير · العجلة للمسافة |
| التفاعل | `E` |
| متابعة الحوار / اختيار الإجابة | `مسافة` أو نقر / `1`–`4` |
| الدفتر · الجرد · الخريطة | `J` · `I` · `M` |
| حفظ سريع | `F5` (والحفظ التلقائي يعمل عند الأحداث وكل دقيقة) |
| قائمة التوقف | `Esc` |

## ما الذي تجده في هذه النسخة

* **الحارة:** ساحة وبحرة، مقهى بعريشة، بقالة، باب الحارة، وزقاق غربي مسقوف؛ أرضيات حجرية، أبلق دمشقي، مشربيات، فوانيس، غسيل معلّق، سكان يتحركون ويعودون لبيوتهم مساءً.
* **الإضاءة:** شمس فيزيائية مع ظلال، ضباب، غروب فعلي ثم ليل بنجوم وفوانيس مضيئة (دورة نهار/ليل متصلة بالقصة).
* **القصة:** مشهد افتتاحي داخل المحرك → تحقيق في اختفاء ساعة جيب → ثلاث شخصيات بحوار متفرع → أربع نهايات تُحسب من خياراتك وثقة الشخصيات.
* **الأنظمة:** تفاعل، جرد، دفتر أدلة، خريطة صغيرة وكاملة، ثقة وسمعة تظهر نتائجها في الحوار، حفظ تلقائي ويدوي، إعدادات جودة وصوت وترجمة.
* **الصوت:** أجواء مكانية، موسيقى مولَّدة على المقامات (بياتي/حجاز/نهاوند) تتبدّل بالمزاج، أصوات حوار مؤقتة بمزامنة شفاه.

## الصدق في الوصف: حقيقي ومؤقت

| حقيقي وقابل للعب الآن | مؤقت (يُستبدل لاحقاً) |
|---|---|
| العالم، الإضاءة، الكاميرا، الحوار المتفرع، الثقة والسمعة، التحقيق، الحفظ، الواجهة، الخريطة | **نماذج الشخصيات** مجسَّمة بأشكال أولية، **أصوات الحوار** تركيبية، **الأسماء** مؤقتة بحسب الدور، والخامات مولَّدة برمجياً |

* لم تُزوَّد اللعبة بمراجع المسلسل، فلم تُنسب إليه أي أحداث. الشخصيات أدوار مؤقتة (`src/story/cast.js`) تُربط بالشخصيات المعتمدة حين تتوفر المراجع.
* المهمة الرئيسية **أصلية مضافة للعبة** وموسومة بذلك داخل اللعبة (الدفتر، الشعار عند البدء، شاشة النهاية).
* لا تُستخدم هيئات الممثلين وأصواتهم قبل وجود تراخيص وموافقات موثّقة. كل شخصية لها `voiceId` وواجهة `Character` ثابتة لتسهيل استبدال النموذج والصوت.

## الاختبار الآلي

اختبار دخان يلعب اللعبة فعلياً بمتصفح Chromium حقيقي (حوارات، أدلة، نهايات، حفظ/متابعة، مهلة المغرب):

```bash
npm i --no-save playwright-core
node scripts/serve.mjs 8099 &
node tests/smoke.mjs               # كل السيناريوهات (أو اسم سيناريو واحد: sitr zulm afw hiba deadline continueSave audio)
```

لقطات الشاشة تُحفظ في `tests/out/` (مستثناة من git).
